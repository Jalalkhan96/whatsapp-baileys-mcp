WhatsApp Session Pair

Link a WhatsApp number and get its Baileys session — QR and pairing code, at the same time.

🔒 Sessions are generated in server memory only — never stored, never logged
The always-on pairing backend (see README). The Vercel page itself cannot hold a WhatsApp connection.
Leave empty if you only want the QR code.
Idle.

📷 QR Code

Your QR code will appear here.
WhatsApp → Linked devices → Link a device
The QR refreshes automatically as WhatsApp rotates it.

🔢 Pairing Code

--------
Your 8-digit pairing code will appear here.
  1. Open WhatsApp on the phone
  2. Linked devices → Link a device
  3. Tap “Link with phone number instead”
  4. Enter the code

✅ Connected — here is your session

⚠️ This session is a full login to that WhatsApp account — treat it like a password and never share it publicly. The pair server has already wiped its copy from memory; this page is the only place it now exists.
Built with Baileys (latest). One socket shows the QR and requests the pairing code together.
The server keeps auth state in RAM only — nothing is written to disk or any database, and state is wiped on delivery, expiry (3 minutes) or cancel.
